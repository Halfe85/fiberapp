# Fiberfinder Angular

Original preserved unchanged in [Fiberfinder-backup](../../tree/Fiberfinder-backup) (commit 617f7f9).

Angular 21 standalone conversion: color-code lookup, fixed/variable tube sizes, comma-separated fiber numbers, striped repeated fibers, original color sequences, saved choices. Mobile-first light UI.

Requires Node >=22.12, `npm install`, `npm run build`. The generated static site must be committed manually for GitHub Pages. No GitHub Actions.

## Branch plan
- Fiberfinder-backup: original static Fiberfinder (immutable backup)
- Fiberfinder-angular: this Angular conversion
- Fiberplaner-angular: independent Fiber Planner development
- main: combined application
