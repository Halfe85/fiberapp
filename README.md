# Fiber Planner Angular

Standalone Angular 21 source for local-first fiber network project documentation. SQLite WASM with OPFS SAH pool; local projects, buildings, entrances, apartments with automatic outlets, switches, ODFs, splice and distribution boxes, ports, cable/patch/splice connections, SQLite export/import. Light mobile-first UI.

This branch is developed separately before combining with Finder on main. It has no GitHub Actions.

Build locally with `npm install` and `npm run build`. Browser persistence requires a secure origin and a browser supporting OPFS; use browser backup/export regularly.
